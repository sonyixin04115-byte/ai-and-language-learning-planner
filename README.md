# 人工智能学习计划

Python 后端与独立 HTML/CSS/JavaScript 前端。按日期自主安排每日任务，完成后勾选，保存实际用时、笔记和历史记录。课程资料库和补充推荐仅供选择，不会自动生成任务。

## 本机启动

需要 Python 3.10 或以上版本。应用使用 Python 标准库，不需要安装第三方依赖。

```powershell
python start.py
```

浏览器打开 `http://127.0.0.1:5174`。首次使用请自行注册账号，数据库会在 `backend/study.db` 创建。后端监听本机 `8001` 端口，前端使用 `5174` 端口。保持启动进程运行，Ctrl+C 停止。

在 PyCharm 打开仓库文件夹，配置可用的 Python 解释器，右键 `start.py` → Run。仓库不包含个人电脑的 `.idea` 配置。

## 功能

- 用户注册、登录、退出及按账号隔离的数据。
- 个人设置中选择头像后先预览，再点击「保存头像」；支持更换、取消更改或移除后保存。保存的头像跟随账号在各设备同步。
- 每日待办表格，勾选完成，修改日期、分类、预计用时、实际起止时间与笔记。
- 任务点击开始后，计时器每秒显示 `HH:MM:SS`；休息时可暂停，回来后继续，勾选完成即停止并保存结束时间。实际投入按「结束时间 − 开始时间 − 暂停时长」自动计算，表单只读预览、列表与日汇总均精确到秒；修改起止时间会自动更新结果。暂停记录保存在账号中，刷新或换设备后仍会保留；历史手工时长会保留。
- 课程和课时表格；视频课时逐节打钩、撤销，自动汇总已学进度；每日任务仍由自己安排。
- 人工智能与其他课程、英语学习、韩语学习分开显示；课程支持来源筛选、P0–P3 优先级和学习范围说明。
- AI 视频导论采用厦大林子雨《人工智能通识——零基础学AI》，导入官方合集的 119 个真实视频入口，逐节打开、打钩并保存进度。优先概述、机器学习概念和伦理；原有 Python、数据分析、机器学习与深度学习实操主线继续按需要使用。视频由原平台播放，不搬运媒体文件。
- 英语按已有四级基础直接进入提高路线：P0 大连理工《英语核心能力提升（雅思篇）》普通话主课，以 Academic IELTS 总分 6.5 为目标；按听说读写 4 个章节分组，已核实的 33 个公开课题逐行打钩。考试日期与每天安排由用户决定，不自动排任务。
- P2 B2 听说读写 41 单元为按需辅助练习，P3 OpenLearn 8 周章节为英文图文参考；英语共 3 门、82 个可记录课题或单元，保留原课时 ID 与进度。中文雅思视频为主课，打开课程后到原平台自行登录、加入并进入课程学习。辅助材料不要求全部完成。各单元的中文名称和原创导学不是原文字幕，不把英文原声课标成中文授课。音频和图文条目也可勾选，雅思课题可能包含多项课件，不把目录数冒称视频数。
- 韩语保留用户指定的平台入口，课程顺序与每天安排自主决定。每日练习区按《延世韩国语》1–6 册的已核验语法知识点提供系统原创中译韩、韩译中题，显示册次、知识点和语法整理资料页码；不发布教材扫描件、原题或原文。
- 英语 A1–C1、韩语第 1–6 册的每日分级翻译与语法复习；每组最多 5 题，可切换方向与日期，独立保存译文、完成和需复习标记。参考表达默认折叠，由本人自评，不把参考译文当作唯一答案或自动判分。原练习内容与作答一起保存，后续题库更新不会改变已领取的题目。
- 本地移动硬盘课程索引、视频播放及资料读取；不会复制视频。
- 学习记录、近期投入统计与 JSON 导出。
- 云端 WSGI 入口，任务、课程进度与目录使用持久 SQLite；可打开自行添加的在线课程链接，本地移动硬盘视频不上传。

课程并非全部必学。可以按自己的基础选择需要的阶段；学习说明不会自动安排每日任务。四级或高考成绩不直接等于 CEFR 或雅思分数，课程不保证取得 6.5。雅思课核验学期至 2027-01-08；原平台可能需要免费注册/加入，认证证书另费，内容与结课后权限以平台为准，不承诺永久开放。通用的公开课程链接和原创语言题库随源码发布，个人课程修改、答案、学习记录和私人教材均保存在各自私有环境中。课程更新只迁移未改动的旧出厂字段，保留个人修改、归档状态和完成进度。

## 导入自己的本地课程

课程索引和媒体属于个人资料，不包含在本仓库。请先启动并注册自己的账号，再按课程集合/课程的两级目录组织资料，然后执行：

```powershell
python backend/import_materials.py --username YOUR_LOCAL_USERNAME --root "G:/人工智能学习"
```

该命令扫描资料文件名并生成 `backend/materials_catalog.json`，课程原文件保留在所选硬盘。拔掉硬盘后目录仍在，视频暂时无法读取。该索引被 `.gitignore` 排除。

## 云端部署

`deploy/wsgi_app.py` 复用原 Python API，在同一 HTTPS 域名服务网页与 `/api`。在支持 WSGI 和持久文件存储的托管平台配置 `deploy/pythonanywhere_wsgi.example.py`。必须替换示例用户名，设置准确的 `STUDY_PUBLIC_ORIGIN` 与私有绝对路径 `STUDY_DB`。

`deploy/package_cloud.py --username YOUR_LOCAL_USERNAME` 可在自己的电脑上生成带指定账号数据的私人迁移包。该包包含数据库，只能上传到本人受控的私有托管空间，不能提交到 GitHub。`deploy/ready/` 和所有数据库文件均被忽略。

云端和本机数据库不会自动双向合并。跨设备使用时，统一登录同一云端网址，以云端数据库为准，任务、计时和逐节进度保存在同一账号。云端只能打开有效的在线课程链接，不能读取电脑的移动硬盘；本地媒体不会自动上传或同步。

## 项目结构

```text
backend/        Python JSON API、SQLite 与受限本地资料服务
frontend/       独立网页、表格布局和交互
deploy/         WSGI 生产入口、示例和私人迁移打包工具
tests/          标准库 unittest 回归测试
start.py        本机双服务启动器
```

## 验证

```powershell
python -m unittest discover -s tests -v
python deploy/test_wsgi.py
node --check frontend/app.js
node --check frontend/task-timer.js
```

Node.js 仅用于可选的 JavaScript 语法检查，运行本系统不需要 Node。

## 数据与备份

本仓库只备份源代码，不包含账号、密码哈希、登录会话、任务数据库、真实个人头像、私人课程目录、视频、日志或备份。头像和记录保存在账号数据中，需由部署者保管并单独备份。JSON 导出用于查阅，当前不提供 JSON 导入恢复。不要公开数据库或私人迁移 ZIP。

### 管理员密码恢复

`deploy/create_password_reset.py` 仅供实例所有者在自己的私有部署环境中按需生成短时、一次性恢复请求。输出的链接和 JSON 文件属于私密凭证，不能提交仓库或发到公开页面。恢复页面不会自动改变密码；使用者本人填写并提交后，请求失效，旧登录会话也会撤销。生成文件默认不包含在源码仓库中。
